def _reset_schema(db: Session) -> None:
    """Empty the database before `pg_restore` — the whole `public` schema, in
    one statement, extension included (CASCADE takes `vector` with it; the
    dump's own CREATE EXTENSION puts it back).

**Interfaces:**
- TS: `type InlineNode = {type:"text"; value:string} | {type:"strong"|"em"|"u"; children: InlineNode[]}`; `parseInlineMarks(text: string): InlineNode[]`; `stripInlineMarks(text: string): string`; `toggleMark(text: string, start: number, end: number, mark: "strong"|"em"|"u"): {text: string; start: number; end: number}`.
- Py: `parse_inline_marks(text: str) -> list[dict]` (same shapes, keys `type`/`value`/`children`); `strip_inline_marks(text: str) -> str`.

Grammar (both sides): scan left to right; markers are `**`, `*`, `<u>`/`</u>`. A marker opens a span only if a matching closer exists later in the text (otherwise it is literal text). `**` is tried before `*`. Spans nest; an unmatched closer is literal. `*` adjacent to whitespace on the inside (`* x*`) is literal (avoids turning "2 * 3 * 4" into italics). Newlines are plain text characters inside spans.
