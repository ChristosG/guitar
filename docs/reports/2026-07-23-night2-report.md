## 2. The crash — τι ήταν στ' αλήθεια

`systemd-oomd` σκότωσε ΟΛΟΚΛΗΡΟ το user session σου (GNOME, browser, όλα) επειδή το
memory pressure του session έμεινε >50% για >20s — Ubuntu default διάσημα επιθετικό.
Πυροδοτήθηκε ~1′ μετά την εκκίνηση του outline, με 6.3GB ήδη σε swap (κυρίως ανενεργά
vllm/qdrant/java από άλλα projects). Το docker stack (system slice) δεν επηρεάστηκε.

**Εκκρεμεί από σένα** (το one-liner με το `!` πιο πάνω στη συζήτηση): ανεβάζει το όριο
στο 80%/60s, βάζει swappiness 10 και αδειάζει το swap. Μέχρι να τρέξει, ένα ακόμα spike
μπορεί να σε ξαναπετάξει έξω. Αξίζει επίσης να σβήσεις τα αχρησιμοποίητα vllm (~3.5GB).

## 5. Systemic insights (η γνώμη μου για το ΣΥΣΤΗΜΑ, όχι το κείμενο)

1. **Οι γέφυρες μαντεύονται.** Τα μαθήματα γράφονται παράλληλα, οπότε κάθε μάθημα
   ΜΑΝΤΕΥΕΙ τι είπε/θα πει το διπλανό του — εξ ου οι σπασμένες «στο επόμενο μάθημα»
   αναφορές. Φτηνό fix για επόμενη φορά: να μπαίνουν στο prompt του κάθε μαθήματος οι
   ΤΙΤΛΟΙ + objectives του προηγούμενου/επόμενου (τα έχει ήδη το outline — δύο γραμμές
   στο LESSON_TAIL). Θα έκοβε σχεδόν όλα τα λάθη ροής.
2. **Οι ελληνικές «νάρκες» είναι επινοημένες λέξεις.** Το μοντέλο, πιεσμένο να γράφει
   ελληνικά, κατασκευάζει λέξεις («τσατάλη», «ταμπλαδούρα»). Μία πρόταση στο
   `shared.curriculum_style` — «αν δεν ξέρεις την ελληνική λέξη, κράτα τον αγγλικό
   όρο· ΜΗΝ επινοείς ελληνική» — θα μείωνε δραστικά το φαινόμενο.
3. **Το «δύο συγγραφείς διαφωνούν» του 5.2** είναι σχεδόν σίγουρα το canon που μιλάει
   (τα DIVERGENCES του). Ενδιαφέρον: η γνώση των διαφωνιών ΕΦΤΑΣΕ σωστά στο μάθημα —
   μόνο η διατύπωση πρόδωσε την πηγή. Ίσως αξίζει μια γραμμή στο style: «τις διαφωνίες
   της βιβλιογραφίας δίδαξέ τις ως "κάποιοι… άλλοι…", ποτέ ως συγγραφείς/βιβλία».
4. **Ποιότητα ανά κόστος**: 24 πλήρη μαθήματα, ~73K λέξεις, 2 λάθη ουσίας ανά ~10K
   λέξεις, σε ~2.5 ώρες και $0 πραγματικό κόστος. Με το fix-pack εφαρμοσμένο, αυτό
   είναι υλικό που διδάσκεται.
